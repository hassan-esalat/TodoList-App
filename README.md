# 📝 TodoList App

یک اپلیکیشن لیست کارهای (To-Do) ساده، سبک و فارسی/راست‌به‌چپ — ساخته‌شده با HTML، CSS و جاوااسکریپت خام؛ بدون فریمورک، بدون ابزار بیلد و بدون هیچ وابستگی.

## ✨ امکانات

- ➕ افزودن کار جدید
- 🔍 فیلتر تسک‌ها: همه / انجام‌شده / انجام‌نشده
- ✏️ ویرایش عنوان تسک با مودال (همراه با نمایش تاریخ ایجاد به شمسی)
- ✅ علامت‌گذاری تسک به‌عنوان انجام‌شده
- 🗑 حذف تسک
- 💾 ذخیره‌سازی خودکار در `localStorage` (ماندگاری داده‌ها پس از رفرش)
- 📱 طراحی واکنش‌گرا (ریسپانسیو) برای موبایل و دسکتاپ
- 🛡 محافظت در برابر XSS با خروجی گرفتن (escape) از متن کاربر

## 🚀 نحوه اجرا

هیچ وابستگی‌ای لازم نیست؛ کافی است فایل `src/index.html` را در مرورگر باز کنید.

یا اگر ترجیح می‌دهید با سرور استاتیک اجرا کنید، از ریشه‌ی پروژه:

```bash
python3 -m http.server 8000
# یا
npx serve .
```

سپس آدرس [`http://localhost:8000/src/index.html`](http://localhost:8000/src/index.html) را باز کنید.

## 📁 ساختار پروژه

```
assets/
├── fonts/              # فونت وزیرمتن (Bold و Regular)
└── images/icon/        # آیکون‌های ویرایش، تیک و حذف
src/
├── index.html          # صفحه‌ی اصلی اپلیکیشن
├── js/app.js           # منطق اپلیکیشن (افزودن، ویرایش، حذف، فیلتر و ذخیره‌سازی)
└── css/
    ├── style.css       # استایل‌های اپلیکیشن
    └── fonts.css       # تعریف فونت (@font-face)
```
